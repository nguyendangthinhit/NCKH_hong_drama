# Dashboard

Dashboard React/Vite. Chạy các lệnh dưới đây trong PowerShell.

## Chạy local

```powershell
cd D:\py\git\NCKH_hong_drama\serving\dashboard
npm run dev -- --host 127.0.0.1 --strictPort
```

Mở <http://127.0.0.1:3000>. Giữ terminal mở; nhấn `Ctrl+C` để dừng.

## Cài đặt lần đầu

Cần Node.js và npm. Nếu chưa cài dependencies:

```powershell
cd D:\py\git\NCKH_hong_drama\serving\dashboard
npm install
```
