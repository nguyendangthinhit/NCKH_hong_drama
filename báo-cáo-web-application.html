1. TỔNG QUAN DỰ ÁN

1.1 Mục Tiêu

Phát triển ứng dụng web để hiển thị và quản lý tin tức từ các nguồn khác nhau, bao gồm Facebook và các trang tin tức công cộng, phục vụ cho nghiên cứu về các chủ đề drama/phim ảnh.

1.2 Thông Tin Cơ Bản

Thông Tin Chi Tiết
Tên Dự Án Drama News App
Phiên Bản 0.0.0
Loại Single Page Application (SPA)
Build Tool Vite
Framework Chính React 19.2.0

2. KIẾN TRÚC HỆ THỐNG

2.1 Sơ Đồ Cấu Trúc

code_web/ ├── src/ │ ├── pages/ │ │ ├── HomePage/ (Trang chủ) │ │ ├── FacebookPage/ (Trang Facebook) │ │ └── NewsPage/ (Trang Tin tức) │ ├── components/ │ │ ├── Header/ (Thanh header) │ │ ├── Footer/ (Chân trang) │ │ ├── PostCard/ (Thẻ bài viết) │ │ └── Pagination/ (Phân trang) │ ├── services/ │ │ └── api.js (API client) │ ├── styles/ (Stylesheet toàn cục) │ └── utils/ (Utility functions) ├── public/ (Static assets) └── package.json (Phụ thuộc dự án)

2.2 Luồng Dữ Liệu

  1. API Service → Tải dữ liệu từ backend API
  2. Pages → Xử lý logic từng trang
  3. Components → Hiển thị giao diện
  4. Styles → SCSS modules cho styling

3. CÁC CÔNG NGHỆ SỬ DỤNG

Công Nghệ Phiên Bản Mục Đích

  • ESLint 9.39.1 - Linting & code quality

12. HƯỚNG DẪN CHẠY DỰ ÁN

12.1 Yêu Cầu Hệ Thống

  • Node.js 16+ (khuyến nghị 18+)
  • npm hoặc yarn

12.2 Cài Đặt

# Điều hướng tới thư mục project
cd code_web

# Cài đặt dependencies
npm install

# Khởi động dev server
npm run dev

# Mở browser: http://localhost:5173
# (hoặc port được chỉ định)

12.3 Build Cho Production

# Build optimized bundle
npm run build

# Preview production build
npm run preview

12.4 Linting & Quality Check

# Chạy ESLint
npm run lint

# Fix linting issues tự động
npx eslint . --fix
